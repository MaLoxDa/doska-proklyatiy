# Доска проклятий

Веб-приложение для заказа эзотерических услуг: ритуалы, консультации, амулеты.

# Технологии

- HTML5
- CSS3
- Supabase (PostgreSQL)

# Структура БД

7 таблиц: users, masters, services, orders, reviews, messages, telegram_notifications.
